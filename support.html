Questions fréquentes

Quels formats sont pris en charge ?

MP3 (ID3v2.2, 2.3 et 2.4), M4A, M4B, MP4 et FLAC.

Comment modifier plusieurs fichiers à la fois ?

Sélectionnez-les dans la liste. Les champs identiques s'affichent ; ceux marqués « ‹ Conserver › » ont des valeurs différentes et ne changent que si vous les modifiez. Enregistrez avec ⌘S.

Pourquoi Sillon me demande-t-il l'accès à un dossier ?

Pour renommer des fichiers ajoutés un par un, macOS exige l'accès à leur dossier. Choisissez le dossier proposé puis cliquez sur Autoriser. Ajouter directement un dossier évite cette étape.

Comment remplir les tags à partir des noms de fichiers ?

Menu Tags › Tags d'après le nom de fichier, puis décrivez le format, par exemple %track% - %artist% - %title%. L'aperçu montre le résultat avant de l'appliquer.

Sillon modifie-t-il le son ?

Non. Seules les métadonnées sont réécrites ; l'audio n'est jamais réencodé. Les fichiers sont enregistrés de façon sûre, via une copie temporaire.

Comment désinstaller Sillon ?

Quittez Sillon et placez-le dans la Corbeille.

Configuration requise

macOS 26 ou version ultérieure, sur Mac Apple silicon ou Intel.

Frequently asked questions

Which formats are supported?

MP3 (ID3v2.2, 2.3 and 2.4), M4A, M4B, MP4 and FLAC.

How do I edit several files at once?

Select them in the list. Shared values are shown; fields marked “‹ Keep ›” have different values and only change if you edit them. Save with ⌘S.

Why does Sillon ask for access to a folder?

To rename files you added one by one, macOS requires access to their folder. Choose the suggested folder and click Allow. Adding the folder itself avoids this step.

How do I fill in tags from file names?

Tags menu › Tags from File Name, then describe the format, for example %track% - %artist% - %title%. The preview shows the result before you apply it.

Does Sillon change the audio?

No. Only the metadata is rewritten; the audio is never re-encoded. Files are saved safely through a temporary copy.

How do I uninstall Sillon?

Quit Sillon and move it to the Trash.

Requirements

macOS 26 or later, on Apple silicon or Intel Macs.

よくある質問

対応しているフォーマットは？

MP3（ID3v2.2、2.3、2.4）、M4A、M4B、MP4、FLACです。

複数のファイルをまとめて編集するには？

リストでファイルを選択します。共通の値が表示され、「‹ 保持 ›」と表示された項目は値が異なり、編集しない限り変更されません。⌘Sで保存します。

Sillonがフォルダへのアクセスを求めるのはなぜ？

1つずつ追加したファイルの名前を変更するには、macOSがそのフォルダへのアクセスを必要とします。表示されたフォルダを選択して「許可」をクリックしてください。フォルダごと追加すればこの手順は不要です。

ファイル名からタグを設定するには？

「タグ」メニュー ›「ファイル名からタグを設定」を選び、%track% - %artist% - %title% のように書式を指定します。適用前にプレビューで結果を確認できます。

Sillonは音声を変更しますか？

いいえ。書き換えるのはメタデータだけで、音声が再エンコードされることはありません。ファイルは一時コピーを経由して安全に保存されます。

Sillonをアンインストールするには？

Sillonを終了して、ゴミ箱に移動してください。
